# PHY public API

`mem_phy.hpp` defines the compatibility `Direct` mode, online `Behavioral` mode,
DFI-oriented lifecycle/FIFO/completion structures, and the HBM/LPDDR protocol adapter API.
The implementation is in `src/phy/mem_phy.cpp`; the architectural and calibration boundary is
documented in `文档/Mem PHY模型.md`.
